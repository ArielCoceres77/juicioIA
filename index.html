CONECTORES MULTIJUGADOR

El juego elige solo el conector disponible. Quien crea la sala y quienes se unen tienen que abrir el juego desde el mismo lugar (el mismo enlace o la misma página publicada).

— Salas de Claude

Funciona cuando el juego se abre desde su enlace de claude.ai. Pueden entrar las personas con acceso a ese enlace: miembros de tu organización o invitados. No hace falta configurar nada.

— Conexión directa (sin cuenta, recomendado para GitHub Pages)

No hay que configurar nada. La compu del juez funciona como servidor de la partida: los celulares se conectan directo a ella usando el servidor gratuito de PeerJS para encontrarse.

  1. La pestaña de quien creó la sala tiene que quedar abierta toda la partida, idealmente en la compu que proyecta.
  2. Necesita internet. Si alguna red escolar bloquea la conexión, probá con los datos móviles del celular.

— Firebase Realtime Database (aula, GitHub Pages)

Opcional: si la cargás, el juego la usa en vez de la conexión directa. Si llegaste al límite de proyectos, podés usar la base de un proyecto que ya tengas: el juego guarda todo en su propia carpeta «juicio».

  1. En console.firebase.google.com abrí tu proyecto (o creá uno) y entrá a Realtime Database → Crear base de datos.
  2. En la pestaña Reglas, pegá esto y publicá:
{
  "rules": {
    "juicio": {
      "$sala": { ".read": true, ".write": true }
    }
  }
}
